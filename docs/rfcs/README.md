# Frozen — historical record only

This directory is closed. **Do not add to it, and do not cite it in new work** — the RFCs here are
point-in-time design documents whose statuses have drifted from reality (0020 says "implementation
not started" about a shipped feature). Current truth lives in [`../specs/`](../specs/); in-flight
changes in [`../changes/`](../changes/); the process in [`../spec-process.md`](../spec-process.md).

Each area pass absorbs the RFCs its spec page covers and **deletes them here** (git history keeps
them retrievable), then sweeps living docs, skills and code comments for references. The directory
disappears with the last pass. Append-only logs (the process journal, retro notes, archived change
docs, PRs) keep their RFC citations — they are records of moments.
